# مشروع منصة Ras Gharib Mobility — رأس غارب موبيليتي

دليل المالك وفريق التشغيل الفني للمرحلة الأولى (MVP).

## 1. نبذة عن المشروع
منصة نقل ذكية متخصصة لربط الركاب بالسائقين في مدينة **رأس غارب** ومحافظة **البحر الأحمر**، تغطي:
1. رحلات التنقل داخل مدينة رأس غارب.
2. رحلات السفر المنتظمة بين المدن (الغردقة، قنا، القاهرة، السويس، الجونة، الزعفرانة، رأس شقير).
3. الرحلات المجدولة مسبقاً مع حجز المقاعد الفردية.
4. نظام طلبات الرحلات وعروض الأسعار التنافسية للسائقين.
5. خدمة شحن وتوصيل الطرود والأمانات بين المدن.
6. لوحة إدارة متكاملة للموافقة على السائقين، وضبط نسبة العمولة، وإدارة الشكاوى والحجوزات.

## 3. هيكل الملفات
```
├── ARCHITECTURE.md          # وثيقة المعمارية التقنية والتكاليف وقواعد العمل
├── prisma/
│   └── schema.prisma        # مخطط قاعدة بيانات PostgreSQL متوافق مع Prisma
├── src/
│   ├── types/               # تعريفات الأنواع الصارمة للركاب والسائقين والرحلات
│   │   └── index.ts
│   ├── store/               # محرك البيانات والحالة التخزينية مع قواعد العمل الصارمة
│   │   └── mobilityStore.ts
│   ├── components/
│   │   ├── Navbar.tsx       # شريط التنقل العلوي المتوافق مع ميثاق التصميم (3-zone)
│   │   ├── HeroSearch.tsx   # محرك البحث عن الرحلات والخدمات
│   │   ├── AuthModal.tsx    # نافذة تسجيل الدخول/الإنشاء مع التحقق برقم الهاتف
│   │   ├── TripsList.tsx    # استعراض الرحلات المنشورة وحجز المقاعد
│   │   ├── PassengerArea.tsx# بوابة الراكب: إنشاء طلب، مقارنة العروض، متابعة الحجوزات
│   │   ├── DriverArea.tsx   # بوابة السائق: إرسال العروض، نشر الرحلات، فحص الأرباح
│   │   ├── AdminArea.tsx    # لوحة الإدارة: اعتماد السائقين، ضبط العمولة، تقارير المؤشرات
│   │   ├── ParcelArea.tsx   # خدمة الطرود وشحن الأمانات
│   │   └── TransparencyBanner.tsx # شريط الشفافية التقنية وبيئة التشغيل
│   ├── App.tsx              # الصفحة الرئيسية وإدارة المسارات
│   ├── index.css            # استيراد خطوط Tajawal و TailwindCSS v4
│   └── main.tsx
├── package.json
└── tsconfig.json
```

## 4. كيفية التشغيل
الواجهة تعمل تلقائياً عبر:
```bash
npm run dev
```
على المنفذ `3000`.

## 5. حالة المرحلة الأولى
- **تم تنفيذه واختباره بالكامل:**
  - واجهة عربية RTL تفاعلية بالكامل ومتجاوبة مع الهواتف والحواسب.
  - تطبيق قواعد العمل الصارمة (منع تجاوز المقاعد، تجميد نسبة العمولة وحساب المستحقات، آلية قبول عرض السائق وإلغاء العروض المنافسة، اشتراط اعتماد السائق لنشر الرحلات).
  - بوابات مستقلة: الراكب، السائق، ومدير المنصة (Admin).
  - مخطط Prisma PostgreSQL الجاهز للنشر المباشر.
  - شفافية تامة حول إرسال الـ OTP الحقيقي وضرورة مفاتيح بوابة الاتصالات.
